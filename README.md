# HR Analytics Dashboard | Power BI

## 📌 Project Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee demographics, income, job roles, attrition, and work-life balance. The dashboard helps explore workforce trends through interactive visualizations and filters.

## 🎯 Objectives
- Analyze employee demographics and job roles.
- Explore income distribution by age group, gender, and job role.
- Understand employee attrition patterns.
- Examine attrition by work-life balance and job level.
- Present HR insights through interactive dashboards.

## 🛠️ Tools & Technologies
- **Power BI** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **Data Visualization** — Charts, KPI cards, and interactive reports

## 📊 Dashboard Features
- KPI cards for key HR metrics
- Employee details table
- Interactive slicers and filters
- Employee distribution by education and job role
- Income analysis by age group, gender, and job role
- Attrition analysis by work-life balance and job level

## 🔍 Key Analysis Areas
1. Employee demographics and workforce distribution
2. Income patterns across employee groups
3. Attrition trends across work-life balance and job levels
4. Job role and education-based employee analysis

## 📁 Project File
- `HR ANALYTICS.pbix` — Power BI dashboard file
- 'HR_Analytics.csv' - Source Dataset

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report pages, charts, KPI cards, and available filters.
